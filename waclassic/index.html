Set up WA Classic

WA Classic brings WhatsApp to iPhones with iOS 4 to 6. Your iPhone talks to a small program, the bridge, that runs on a computer in your home and is linked to your WhatsApp account like WhatsApp Web.

What you need

  • A jailbroken iPhone with iOS 6 (iOS 4.3 build for the iPhone 3GS).
  • Your phone with WhatsApp. It stays your main device; WA Classic is a linked device.
  • A computer that stays on: a Mac, a Windows PC, a Raspberry Pi or a NAS. While it sleeps, no messages reach the iPhone.

1 Install Docker

Docker runs the bridge in its own box, so nothing else on your Mac changes.

Download Docker Desktop for Mac
  1. Pick Apple Silicon (M1 and newer) or Intel. Not sure? Apple menu › About This Mac.
  2. Open the downloaded file and drag Docker into Applications.
  3. Start Docker from Applications and accept the terms. You can skip signing in.
  4. Wait until the whale icon in the menu bar stops moving.

Docker runs the bridge in its own box, so nothing else on your PC changes. Windows 10 or 11 (64-bit) is needed.

Download Docker Desktop for Windows
  1. Run the installer and keep Use WSL 2 switched on.
  2. Restart the PC when the installer asks for it.
  3. Start Docker Desktop and accept the terms. You can skip signing in.
  4. If Docker asks to install or update WSL, allow it and start Docker again.

Open a terminal on the Raspberry Pi (64-bit Raspberry Pi OS) or Linux computer and run:

curl -fsSL https://get.docker.com | sudo sh

This is Docker's official install script. On a NAS (Synology, QNAP, Unraid) install the Docker or Container app from its package center instead.

It downloads the bridge (a few hundred MB), starts it and starts it again after every reboot. Your chats and the link to WhatsApp are kept in the Docker volume wa-classic-data.

Windows asks whether Docker may use the network: allow it for private networks, otherwise the iPhone can't reach the bridge.

3 Open the setup page

Open localhost:8097

The page guides you through the rest:

  1. Choose a password for the page.
  2. On the iPhone add the Cydia source that the page shows (like http://192.168.1.20:8097/repo/) and install WA Classic from it.
  3. Open WA Classic and enter the address and code that the page shows.
  4. The iPhone then shows a QR code: scan it with WhatsApp on your phone (Settings › Linked Devices › Link a Device).

The iPhone needs the address of this computer in your home network (like 192.168.1.20:8097), not "localhost". Open the setup page once with that address and it shows it to you.

4 Keep it running

  • Docker Desktop › Settings › General: turn on Start Docker Desktop when you sign in.
  • System Settings › Energy (or Battery › Options): turn on Prevent automatic sleeping when the display is off. A MacBook has to stay plugged in and open, or use an external display.
  • Docker Desktop › Settings › General: turn on Start Docker Desktop when you sign in.
  • Settings › System › Power: set Sleep to Never when plugged in.
  • Nothing to do: the bridge starts with the computer.
Update the bridge

Run these lines one after another. Your chats and the link to WhatsApp stay.

docker pull ghcr.io/aronsz26/wa-classic-bridge:latest
docker rm -f wa-classic

Then run the line from step 2 again.

Remove everything

First unlink WhatsApp on the setup page (Manage › Unlink WhatsApp), then:

docker rm -f wa-classic
docker volume rm wa-classic-data
Something doesn't work
  • The setup page doesn't open: is Docker running? docker ps should list wa-classic. The log shows what happened: docker logs wa-classic
  • The iPhone can't reach the bridge: it has to be in the same Wi-Fi, and the address must be this computer's address in your home network. On Windows, check that Docker may use private networks in the firewall.
  • The code is wrong or expired: press New code on the setup page.
  • Forgot the setup page password: docker exec wa-classic rm /data/admin.json, then reload the page.
